# VI Guide — pacote de dados

Arquivos JSON lidos pelo app VI Guide (itens, missões, cheats, mapa). Publicado via GitHub Pages; o app baixa só o que mudou (`manifest.json` traz o sha256 de cada arquivo).
Fatos de itens e missões vêm da gta.wiki (CC BY-NC-SA 3.0); textos são nossos. Projeto de fã, sem afiliação com a Rockstar Games ou a Take-Two.
